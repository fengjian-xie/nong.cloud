# 乡桥：农事中心、云农场与多身份工作平台

连接乡土，共享丰收。本仓库从福安一期原型扩展为五站Web入口与一个多身份原生小程序。以下是代码范围，不是生产能力上线声明。

- `admin-web/`：React + Vite + TypeScript；官网、管理后台、乡桥农场、开放API展示、用户工作台共用代码库，分别构建。
- `miniapp/`：原生微信小程序；11个已注册路由，含原型及新数据库联调入口，保留共享业务模块和多身份演示。
- `backend/`：Java / Spring Boot / PostgreSQL / Flyway核心业务后端，已实现认证、多身份、地块、记录、服务工单、帮助消息、农事卡未验证事件、基础内容与审计。
- `contracts/`：历史一期契约及本轮实际已实现的接口清单；以 `local-backend-v1.md` 区分运行能力和规划。
- `docs/`：需求、标准、财务边界和架构复查。
- `design-concepts/`：界面视觉基准。
- `deployment/`：分站部署脚本与历史发布记录；以每次发布记录为准。

入口分工：`nong.cloud`农事中心首页；`m.nong.cloud`管理后台；`nc.nong.cloud`乡桥农场；`api.nong.cloud`开放API；`work.nong.cloud`多身份用户工作台。弃用`nongfu.tech`。

当前建设基线见[全栈架构递归复查](docs/乡桥全栈架构递归复查-2026-10-06.md)。角色共用业务底座，不分别建独立数据库；支付商户和分账管理仅在管理后台。

## 九中心整合版 V4

后台侧栏由32个平铺入口收拢为9个业务中心：运营、组织主体、生产记录、农事服务、产品交易、核验追溯、客户内容、财务结算、平台安全。对应`/manage/:centerId/:section`；旧链接保留跳转及筛选参数，成员/地块/服务/任务详情ID保留。

主体工作台与小程序共用`miniapp/utils/business-groups.json`目录。成熟/供货、成本/经营、库存/分级合为一个入口内的不同视图；原角色不因此获得新增权限。修改目录后运行`node miniapp/tools/sync-business-groups.cjs`生成原生JS模块，使用`--check`核对。

商家信息权益留在产品交易，支付商户及分账移到独立财务中心，并检查演示岗位能力。工作台旧履约反馈进入帮助组件；旧草稿保留原存储，不自动转成工单或已核验资料。小程序换账号保留其他账号的隔离草稿，明确退出只清理当前账号所有身份的数据。网页优先使用苹方-简，非苹果设备使用备用字体。

V4是导航、UI与演示流程整合，不是统一业务数据库的完成证明。地块/产季档案、成本/经营输入、草稿和公开投影仍存在不同演示来源；可信对象ID、证据版本、跨端工单、库存及财务事务仍按V3报告待建设。没有自动迁移或删除已有业务草稿，也没有远程部署。

最新审查见[全栈递归审查V3](docs/乡桥全栈递归审查-V3-2026-10-06.md)，包含产季记录、批次履历、供货、成本、库存、帮助和跨端联动，以及本轮尚未修复的反例。此前[网页与小程序递归审查V2](docs/乡桥网页与小程序递归审查-V2-2026-10-06.md)保留作历史基线。业务身份按产区配置，复用稳定流程模板；目录定义、用户身份授权和管理员权限彼此独立。新增后台目录草案尚未成为网页/小程序的正式可申请身份。

农事卡带来的产品与服务可能性见[农事卡产品价值与试点建议](docs/农事卡产品价值与试点建议-2026-10-06.md)，其中规划不代表已实现功能或确定收益。

## 运行运营后台

首次在 Mac 或另一台电脑上编辑（先安装 Git 和 Node.js 22 LTS）：

```bash
git clone https://github.com/fengjian-xie/nong.cloud.git
cd nong.cloud/admin-web
npm ci
npm run dev
```

换电脑前先检查本地改动并妥善保存，再同步仓库。提交时只选择本次需要的源码，勿提交密钥、私密配置、依赖目录或包含真实个人资料的导出文件。推送需要仓库写入权限。

```powershell
cd admin-web
npm install
npm run dev
```

管理后台原型使用合法11位手机号和Mock验证码`000000`；不是真实短信认证，也不代表可信租户隔离。不同站的演示会话不等于生产统一登录。

## 当前实现边界

- Web和小程序均有角色页面、地块/农事/服务等演示；本地数据不是跨账号、跨端的共享业务数据库。
- 小程序包含农场、消息、添加角色和地址下拉；身份申请只保存演示草稿，不自动授予角色。真实全国乡镇地址库仍需接入。
- 新增统一帮助中心：小程序、PC工作台和农场提供问题登记原型，管理后台提供受理队列；各端尚未后端互通，热线/坐席/回访未接入。说明见[帮助中心与呼叫中台](docs/乡桥帮助中心与呼叫中台-2026-10-06.md)。
- 管理后台包含商户与分账管理说明、测算原型；没有真实支付、执行分账、提现或财务对账接口。
- 本轮新增日志、第三方接口、管理员权限、新闻、社交账号、公司与服务中心、产区身份设置七个管理页面，路由为`/settings/{logs,integrations,permissions,news,social,centers,identities}`。官网新闻与三平台图标已做本机预览；真实账号未配置，新闻和配置不跨域发布。详见V2审查及待发布记录。
- 新增“记录与产品价值”：批次履历、采收供货日历、产季记录、经营净收益、分级货源匹配、跨年对比、协同缺项和履约反馈。管理入口`/production/value/passport`，主体入口`/workspace/:role/value-*`，小程序`pages/value/value?view=…`。经营账不向采购/消费身份开放，媒体记录仍为待本人确认草稿，关注和需求不自动派单或锁库。
- 官网`#product-value`介绍六类价值，农场`/?view=products`展示最小公开示例；公开站不读取管理端或主体账号缓存。不生成假二维码、实际质量认证或金融资格；正式批次对应、公开版本与跨端联动待后端。未来接口追加见`contracts/api-v1.md`产品价值章节。
- 农户平台服务费0；办卡、补卡100元/张。消费者平台服务费0，不代表产品或配送免费。
- 硬件、微信登录、摄像头、合同、支付、追溯报送、生产对象权限及跨中心账本尚待工程建设。
- 切换Mock URL不能完成上线：先建设可信身份与对象授权、类型化关系表、设备协议、库存/财务事务及外部验签，按契约联调和验收后再接入。
