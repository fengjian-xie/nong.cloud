数据按账号＋主体身份隔离，仅存在本机；切换身份不串草稿，切换演示账号保留其他账号的数据，明确退出只清理当前账号全部身份。浏览器预览与原生微信的存储互不共享。请先保存当前草稿，再返回工作台切换；没有自动保存保证。

V4工作台按工作待办、生产记录、农事服务、产品交易、主体授权、帮助反馈分组，不再另建“记录与产品价值”组。业务视图共用入口，旧模块和草稿存储保留；同一入口不意味着后端账本已统一。`utils/business-groups.json`是Web/小程序共用的导航目录，`node tools/sync-business-groups.cjs --check`验证原生生成文件一致；修改目录后去掉`--check`重新生成。财务与分账不进入小程序。

## 核心业务边界

农户平台服务免费；办卡100元/张、补卡100元/张；产品与服务实际价款另计。成本采用经确认的出工人天，现金成本与家庭劳动估值分开；×1.35为可调整参考，不承诺最低成本、保底价或零售企业真实规则。行情来源尚未接入，原型未输入的租金、折旧、税费不能视为已计入。

购买不等于施用，按键次数不等于人天，完工不等于验收，双身份不等于独立验收人。照片/视频字段只是待接入说明，不构成已上传证据；保存地块修改草稿不会改正式档案。报告须独立核验，乡桥记录核验不是绿色食品官方认证。

商户号、分账规则、异步分账、对账和退款仅在PC管理后台设计，不出现在小程序工作台。正式财务权限必须独立审核；不得把普通角色申请与财务授权等同。

## 接口接入交接

`utils/catalog.js`为演示权限及页面定义，`utils/session.js`为演示会话；不是生产鉴权。未来替换为服务端返回的账号、主体成员关系、角色与对象权限，不把前端传入角色作为授权。服务端统一对象ID、租户隔离、自然人去重、幂等、版本、附件访问和审计。

卡片需硬件团队提供设备UUID、协议、密钥、NFC能力、配置版本及回执定义。正式同步为：设备事件 → 手机读取 → 服务端持久化 → 确认回执；丢网、重传、设备重启、手机换绑要真机验证。当前不存在真实数据上传队列或Wi-Fi模块。

公开农场使用专门授权摘要，不能透传原始定位、家庭资料和私人成本。关注/意向/售后草稿不是后端订单或真实通知。生产网关尚未开放；不向 api.nong.cloud 的503占位接口发写请求。AppSecret、支付证书和设备私钥只能保存在受控服务端/设备中。
