# WorkBuddy 六方只读交叉审查任务包

本文件只含非敏感产品约束。WorkBuddy CLI 登录并通过固定连接测试后，才通过本地桥接的显式快照审查发送；不自动读取整个仓库，不启用工具写入，不获取数据库、证书、密码或真实用户明细。当前尚未发送或取得答复。

请独立从种植户、采购商、农机手、农资商、农服/植保队、政府部门六个角度提出反对意见。不要只肯定项目，不把自己当成真实受访客户。输出每类用户最重要的三条风险、最小必需流程、与其他角色的利益冲突、需要向项目方确认的选择，以及实现优先级。对下面已有改进专门找反例。

项目为中国县域农业服务平台：小农户通过实体按钮记录器采集农事，离线保存，软件上传后形成产季记录；同一账号可有多身份，身份经中心批准，数据按中心与主体隔离。硬件调试暂后置。种植户不收平台会员服务费，办卡和补卡各100元/张。采购商可能会员或按条付费，会员方案一般999元以内，正式政策未定。消费者浏览生产与认购不收平台服务费，但真实合同/摄像头尚未接通。

已有本地接口、PostgreSQL、网页和小程序浏览器预览支持：身份申请、云端办卡/补卡/挂失、人工记录、冻结标准的服务需求/工单、会员申请/独立审批、库存预留、卖方确认/登记发货/买方独立验收、下级中心及商户侧分账计算计划。不能跨自然人身份自验收，不将按卡记录视作法定认证。采购按千克计量，金额整数分；库存预留有行锁、版本及幂等保护。

本轮新增：会员待审核/待付款本人可撤回，已生效不能在此撤回；未接单服务需求仅发起人可取消，已接单不能直接取消；与接单竞争同一行锁。取消保留原因、UTC时间、操作者及操作日志，不代表退款。网页和小程序共读当前身份的办事/验收指引，失败不阻断业务列表。等级标为卖方自报，不等于检测结果。

未接通：授权家庭代办、农资销售/批号/交付/实际使用独立台账、服务能力/资质匹配、争议调解/退货退款、批次质量与货权核验、成熟预测、成本估算、官方追溯同步、政府专用授权及汇总、真实支付分账和硬件验签。分账仅后台计算，不在小程序配置，不执行资金操作，不从农户扣平台服务费。

请重点反驳：老人依然需要补录是否违背初衷；付会员费是否必然获得私有数据；购买农资自动生成施用记录是否错误；库存过期与争议能否长期卡住；同一用户多个身份是否重复计数；政府数据权限是否被管理员角色掩盖；服务方无资格仍能看到接单按钮的风险如何最小化。提出建议，但不要执行修改或声称外部服务接通。
