## 3. 导航与视觉内容

统一底部导航：**首页｜工作台｜农场｜消息｜我的**。保持入口稳定，工作台内部按当前身份展示模块；游客进入工作台时提示登录，不默认授予业务身份。

### 3.1 首页

从上到下：

1. 正式乡桥VI标志、名称和Slogan，县域切换默认福安市；定位权限未授予时允许手动选区域。
2. 主文案：“让农事有记录，让好产品被看见。”副文案：“从一张农事卡开始，连接种植、服务、采购与消费。”
3. 快捷入口：我的工作台、同步农事卡、找农事服务、看成熟货源、逛乡桥农场、申请加入。
4. 已登录者展示待同步、待确认、待验收等与本人有关的任务；游客显示产品介绍，不展示虚构个人待办。
5. 福安葡萄产业带：使用用户提供的葡萄、产地体验和农场航拍照片；明确“资料影像”，不用照片冒充实时直播。
6. 成熟货源与产业服务资源的获授权公开摘要，含更新时间和预计/已采收状态。
7. 农事卡介绍：单排开工、收工、A、B、C；按键记录、GPS辅助匹配、离线保存、蓝牙同步、NFC服务衔接。
8. 农事中心成员、服务范围、准入与执行标准、申请入口、公司介绍。
9. 费用及业务边界：“农户免平台服务费；办卡100元/张，补卡100元/张。实际农资、农服和产品价款另行约定。”

主要按钮文案：进入工作台、连接农事卡、寻找服务、查看成熟货源、进入乡桥农场、申请成为成员。

### 3.2 工作台

顶部固定显示“当前经营主体＋当前身份＋切换”。其下为角色欢迎语、今日任务、常用业务、最近单据、异常提醒。明确区分“我作为种植户发出的订单”和“我作为农服队接到的订单”。

公共快捷工具：识别农事卡、扫一扫、现场拍照、任务验收、离线草稿。是否可用由服务端权限和设备能力共同决定，不能通过界面切换自己开权限。

### 3.3 农场

公开浏览农场与产品方案，可筛选地区、产品、采收窗口、影像类型和真实设备状态。查看私有信息、关注、认购或售后时再要求适当登录和授权，不强迫游客先提供手机号。

### 3.4 消息

待办、订单、记录、设备、系统五类消息；正文包含关联对象、触发原因、时间、当前状态及可执行动作。订阅通知作为可选提醒，不以拒绝订阅阻断基础业务。拒绝通知后仍可在站内查看。

### 3.5 我的

账号资料、主体与身份、加入申请、农事卡、家庭委托、交易与单据、查看权益、隐私与公开授权、反馈与申诉、关于乡桥、退出登录。全账号退出须清理各身份敏感缓存，不仅退出当前角色。

### 3.6 VI与易用性

沿用已确认的正式三笔乡标志，不采用早期未确认的LOGO提案。森林绿#0F3D2E、田野绿#3E9B5F、丰收金#E8B54A、纸白#F4F2EA。金色用于少量主按钮，状态不得仅靠颜色区分。

默认清晰中文、较大文字、短表单、可读错误提示；主操作提供足够点击区域和系统字体适配。正文和表单不大量使用装饰性字体。定位、蓝牙、相机按操作时机解释用途并申请，不在首次打开时集中索取全部权限。

## 4. 一个账号、多主体、多身份

账号、经营主体、角色、委托四项必须分开。

示例：同一账号可在本人种植主体中作为种植户，在狮子头农服队中作为工作人员；同一合作社也可以有农资经营与农服业务。登录一次，切换已批准的“主体＋身份”，不重新注册。

登录后服务端返回账号可用主体、身份、业务权限和委托有效期。初次进入可恢复上次仍有效身份；身份已撤销则返回选择页。切换后重新请求相应数据，避免上一身份的成本、客户或订单残留。

身份申请：选择已有主体或申请新主体→选择业务身份→查看对应准入清单→提交必要资料→中心审核→补充/通过/不通过→启用获批权限。消费者浏览不需要经营主体准入。角色标准参考现有14类准入及12环节验收草案，正式资质要求由对应经营业务另行核实。

地块权利人与合作社授权、组织成员资格和县域归属不是同一权限。所有写操作、下载和详情查询都需要服务端对象级检查；隐藏按钮不是鉴权。

### 4.1 多身份登录的强制要求

一次微信登录对应一个乡桥平台账号。申请第二个业务身份时，增加该账号的主体成员关系或角色授权，不新建重复账号；身份切换不触发重复登录，会话过期时按正常流程重新验证。

| 同一用户的组合 | 进入方式 | 切换后的业务界面 |
| --- | --- | --- |
| 种植户＋农服队 | 一次登录后选择当前主体/身份 | 种植户看自己的地块与发出的服务单；农服队看受托订单和队员 |
| 合作社负责人＋农资商 | 同一账号拥有经审核的两类业务授权 | 合作社管授权社员；农资门店登记商品批次与销售凭据 |
| 农机手＋植保团队 | 分别完成适用准入及组织授权后切换 | 共用履约流程，分别展示设备、受托范围与专业作业字段 |
| 种植户＋消费者 | 业务工作台与个人农场共用账号 | 私有生产资料与本人认购订单分开，不因认购取得他人生产权限 |
| 子女代办＋本人种植户 | 显式选择本人主体或父母委托范围 | 本人业务与代理业务分开，代理记录标注代办执行人 |

切换弹层先显示当前经营主体，再列其可用身份；允许跨主体切换，但只显示服务端认可的选项。未保存表单切换前提示保存草稿或放弃，正在传输的设备任务先安全中止/保留进度，不将原任务自动改归新主体。

消息可以集中在一个账号中，但每条标注所属主体/身份；打开后校验目标身份和对象授权。跨身份批量操作暂不开放。统一退出使整个账号会话失效，撤销单项委托则只移除相应访问资格。

PC端已有账号与微信账号的关联，应由可信服务端在用户验证后绑定，不能凭相同姓名、手机号展示值或前端传入的角色合并。登录凭据刷新由平台维护；一次登录的用户体验不等于永不过期的会话。

新增验收案例：种植户登录后切换农服队不再次登录；相同角色在不同组织只看到对应数据；未绑定身份深链被拒绝；撤销委托立即停止代理访问；切换不带入旧主体表单/缓存；同一自然人不能靠切换身份完成自验收。

## 5. 各角色工作台内容

下列11类沿用现有PC角色标识，便于两端共用数据。消费者是公开/个人业务入口；现场运营人员是已有中心授权的移动扩展。无人机手可先作为植保团队专业子类型，技术顾问作为后续独立专业身份，不自动继承其他角色权限。

| 身份与标识 | 工作台页面 | 首要动作与数据范围 |
| --- | --- | --- |
| 种植户 farmer | 我的地块、农事记录、农事卡、土壤肥力、成本定价、服务、供货、家庭授权 | 自有或合法经营地块；查看记录、找服务、确认验收、发布本人允许公开的货源 |
| 合作社 cooperative | 授权社员、地块与产季、卡片代办、记录协同、调度、集体供货、库存 | 只管理已授权社员及本主体业务，不因加入合作社自动取得全部个人数据 |
| 采购商 buyer | 成熟地图/日历、货源详情、采购需求、询价、收购交接、库存共享、信息权益 | 公开或被授权摘要、自己的采购订单；不看农户私人成本、原始轨迹和家庭资料 |
| 农资商 supplier | 识卡销售、商品与批次、销售凭据、待确认交易、退货 | 本门店交易；购买不自动成为施用记录 |
| 农机手 machine | 指派订单、接单、作业凭据、待验收、自有设备、服务时间 | 本站/本人受托订单和设备，不读取全县农户档案 |
| 农服队 team | 服务订单、成员安排、作业记录、完工提交、验收反馈、资源 | 本队受托任务；服务方不能独立验收自己的完工单 |
| 植保团队 protection | 服务订单、施用档案、药剂批次、作业范围、专业人员、设备、异常 | 增加适用的药剂、用量、单位、面积、标签要求和专业凭据；不硬编码所有作物相同参数 |
| 冷库 warehouse | 库位与库存、入库、出库、货主委托、环境记录、运营状态 | 本库保管批次；保管权与销售货权分开 |
| 加工分拣 processor | 投入批次、分级产出、损耗、补货需求、共享库存、交接 | 本车间批次；确认质量和货权后发布，不能重复计算投入与产出库存 |
| 检测机构 lab | 受托任务、采样、检测数据、报告、施肥建议、补充资料 | 本机构受托样品；提交报告不等于自行通过平台核验 |
| 子女代办 family | 授权地块、记录同步、卡片配置、农场故事、代办清单 | 依授权分别开放查看、同步、配置、确认和发布；亲属身份不自动授权 |

### 5.1 农资商识卡销售页面

页面顺序：选择门店→检查NFC/蓝牙能力→识别卡片或输入替代标识→显示最小必要持卡主体→获得本次交易关联许可→选择商品/生产厂家/登记标识等适用字段→批次、数量、单位、单价、总额→凭据照片→农户本人或合法代办确认→保存销售凭据。

“识卡成功”“交易待确认”“已确认购买”“退货”分开显示。允许经本人授权关联地块/产季，但不强制把整笔购买计为某块地的实际施用量。

### 5.2 农机、农服、植保共用履约页

任务卡包含委托方、订单号、作业类型、约定范围、地块必要信息、时间、价款约定、验收条件和当前状态。流程为待接单→已接单→作业中→待验收→已完成；另有取消、争议、整改分支。

完工提交包含实际作业、人数/时长、作业面积与来源、照片/视频及异常。农机增加设备及工时，农服增加队员分工，植保增加专业明细。非施药巡检不能被强制填写不存在的施药量。

识卡是关联任务的一种方式，不自动接单、计费或验收。一人同时是种植户和服务方时，涉及本人提供服务的验收必须执行独立复核规则，不能切换身份自验收。

### 5.3 采购与收购页

成熟货源展示：乡镇、品种、预计采收窗口、公开面积/意向供货规模、更新时间、预测依据和核验状态。详情按权益及公开许可展示，不以购买会员绕过生产者授权。

收购登记：识别持卡主体→确认卖方及其销售授权→关联地块/产季/采收批次→事前约定等级与单价→毛重/皮重/净重及计量单位→抽检或交接凭据→双方确认→应付、已付和结算凭据。换算展示支持斤、公斤，服务端统一计量。

明确交易买方是谁：乡桥自营收购、合作社收购或第三方采购商，不将平台展示等同于平台承担全部订单责任。报价、验收和付款状态分别记录。

### 5.4 库存共享页

展示品种、等级、允许用途、可供净重、货权主体、保管设施、产地、采收/入库日期、保存条件、有效期依据和最后核实时间。支持发布“B级货采购需求2000斤”等具体需求。

同一批次的可用、预留、已交付、损耗由服务端库存账本核算；预约有释放期限，不能本地减数就算锁货成功。质量异常批次隔离，不能以尾货名义继续流通。第一期先做需求和意向匹配，实际库存交易后置验证。

## 6. 地块、农事卡与生产档案详细页面

### 6.1 地块列表与详情

列表：名称、经营人、面积、品种、产季、预计采收、资料状态。详情分为概览、边界地图、种植历史、农事记录、土壤报告、成本、服务、采收批次、公开设置九栏，按权限显示。

建档字段：地块编号、经营主体、经营关系、边界点及坐标系、面积和计算方法、位置、海拔及其来源/误差、作物品种、种植起止、当前产季、照片与资料。

测绘提供两种交互：地图逐点圈定边界；获准并经真机验证的现场采点。预览边界闭合、面积、异常点和精度后再提交。手机位置/海拔不是法定测量或土地权属证明；定位不足可人工标点、导入经过核实的边界或申请中心协助。卡片GNSS与地图坐标分别记录来源，不能直接混用。

已提交种植产品信息的修改：变更原因＋现场照片＋现场视频＋原版本对比→提交审核→通过后生成新版本。确有拍摄障碍时走中心现场核验，保留异常理由和替代凭据，不允许静默绕过。历史产季、原事件和证据不能覆盖。

### 6.2 农事卡页

卡片详情：卡号、绑定主体、绑定状态、电量及读取时间、最近设备连接、最近服务器接收、未确认事件、固件/配置版本、A/B/C当前设备配置和平台目标配置。

设备约束：身份证大小设计目标、厚度不超过身份证三倍；单排开工/收工/A/B/C，GPS/GNSS、离线存储、BLE、NFC、指示灯；无Wi-Fi、无震动蜂鸣，不以前期地块标签为依赖。月充电频率、厚度和防水由20样机验证，界面不得宣称已达标。太阳能不是首期必备。

主要操作：办理、领取/绑定、激活、连接、读取记录、上传记录、设置A/B/C、检查配置回执、挂失、补卡、查看费用单据。办卡及补卡100元/张；价款支付接入前不伪造支付成功。

挂失后阻断旧卡新增业务关联；挂失前离线记录按设备事件时间、可信程度和人工核实规则处置，不简单丢弃或伪装为补卡新记录。补卡有新设备身份，历史生产档案仍保留。重新绑定不能把上一持卡人的记录转给下一人。

### 6.3 A/B/C配置页

展示固定“开工”“收工”，只允许配置A、B、C。示例可选修剪、灌溉、施肥、除草、巡田、采收；专业作业可按资质/流程要求配置，不因设置按键自动获得专业经营权限。

选择作业词典、填写简短说明、查看适用产季→保存平台目标版本→连接卡片下发→校验设备确认。状态为待下发、下发中、设备已确认、失败待重试。平台保存成功不等于卡片生效；无卡在线时必须显示“等待连接农事卡”。

历史事件使用采集时的配置版本解释。仅在下载配置历史或人工核实后解析未知版本；禁止用新的“A=采收”重新解释旧的“A=修剪”。本地临时自定义内容需保存稳定编码和显示名称。

### 6.4 同步页与失败页面

分开显示：卡中已保存、手机已读取、服务器已接收、待人工核实、设备已确认回执。同步进度显示本次读取数、上传数、重复数、失败数；只有拿到服务端持久化回执才提示“上传完成”。

卡片独立记录无需手机常伴。代办打开小程序并靠近卡片后，主动连接读取；手机无网可保留受控待传队列，恢复网络并重新确认授权后上传。不能承诺小程序关闭后持续蓝牙采集或无限后台上传。

按设备身份/绑定周期、持久化序号和协议规定做去重；恢复出厂、换绑定和设备时钟不可靠时有独立分支。固件工程师须确认序号生命周期、签名机制及清理条件，不能直接照搬Mock序号。

先持久化，再服务端确认，再设备确认回执/允许清理。断电、传输中断或无服务器回执时保留原记录，支持断点续传。传输校验只防损坏，不能代替设备身份校验及业务授权。

失败提示包括：蓝牙未开启、没有附近设备、设备不属于当前授权范围、传输中断、手机储存不足、无网络、上传失败、配置版本缺失、卡片挂失、设备时钟异常。每项给重试或人工协助入口，不只显示错误码。

### 6.5 农事记录与纠错

列表按地块、产季、作业、日期、来源和核验状态筛选；详情包含原始事件、当时配置、设备时间/接收时间、GPS精度/无定位原因、地块候选、补充资料与版本链。

设备GPS结合已测绘地块边界匹配；地块相邻、边界精度不足或定位失败时标记“待确认”，由有权限人员选择并填写依据。无需前期额外地块标签，不以一个坐标自动证明实际作业质量。

人数、实际工时、实际投入品用量及单位另行补充。开工/收工跨度不直接等于劳动天数，购买量不直接等于施用量。修改采取追加更正，原始事件不可删除覆盖；代理操作必须标明执行人和委托依据。

### 6.6 肥力、成本与供货

肥力页展示检测机构、样品位置/深度和采样日期、报告版本、检测方法与项目单位、核验状态、建议施肥及依据；不把土壤肥力报告当成产品安全合格证明。

成本页分别展示现金支出与含家庭劳动等完整估算。人工按经确认人数、时长、折算规则和当地行情计算，农资按实际施用而非全部采购量计算，补充机械、土地、折旧、包装、物流和损耗等按用途适用项目。缺项、重复计入和行情日期可见。

单位成本需说明分母为预测产量还是实际可售产量；产量为零或未知时不输出假单价。“成本×1.35”是用户可调整的报价参考，不是法定最低价、保底收购承诺或对企业实践的事实背书。私人成本默认不对采购商公开。

供货页由种植方选择公开字段、品种、预计成熟窗口、意向可供量、是否已采收、意向价和联系方式开放范围。供货预测与库存实物分开。

7. 演示模式：仅生成本机或测试环境明确标注的意向，不采集不必要真实敏感资料，不收款、不形成合同。
