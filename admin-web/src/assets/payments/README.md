These identify account-management entries in the mock frontend; they do not
indicate live payment integration or endorsement. Brand ownership remains with
the respective providers. Review applicable brand-use permissions before production.

- WeChat Pay: https://pay.weixin.qq.com/ — https://td.cdn-go.cn/enterprise_payment/v0.1.2/logo.svg (green symbol path extracted unchanged from the official SVG).

The PNG originals are preserved. CSS shows the symbol area of their wordmarks.
Assets are bundled locally to avoid third-party image requests in the UI.
