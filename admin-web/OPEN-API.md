# 乡桥API开放平台（前端设计稿）

目标独立站点：`https://api.nong.cloud/`；本地独立预览：`/api-portal`。后台「系统管理 → API开放平台」保留管理演示入口 `/open-api`。各栏目支持 `?tab=overview|catalog|apps|debug|logs|guide`。

独立入口不要求管理员会话，也不加载后台侧栏与农户数据上下文。域名与Nginx部署准备见`deployment/API-SITE.md`；尚未实际发布。

## 已完成

- 概览：业务分类、接入步骤、真实边界提示。统计来自当前本地操作，不伪造网关数据。
- 接口目录：8个接入草案，分类与搜索、权限、参数、请求示例、cURL及OpenAPI 3.0.3 JSON导出。
- 应用管理：按用途申请最小接口范围；模拟审核、演示密钥版本轮换及停用。敏感操作须确认。
- 本地调试：模拟200/400/401/403/409/429、分页、字段验证、示例对象白名单、幂等重放及一分钟配额窗口。
- 调用日志：应用、状态筛选；当前会话最近50条，无正文或凭据。应用操作留痕最近30条。
- 接入指南：应用鉴权、对象授权、离线写入、回调与正式上线清单。

## 演示存储与安全边界

应用元数据使用版本化键 `xiangqiao-open-api-demo-apps-v1`，仅保存名称、虚构主体、用途、接口范围、演示状态/版本、配额、回调配置。缓存读取校验，剔除额外字段；读写失败会提示。**请勿输入真实凭据或敏感主体信息。**

`DEMO_NOT_VALID_…`展示串只在内存中显示一次，不是真实Secret或访问令牌。调试仅对比本地演示版本，不能作为正式鉴权机制。日志、请求正文、响应、幂等缓存和展示串不持久保存。当前会话最多1000次调试、20个演示应用。

调试不调用fetch，不访问填写的回调地址，不连接实物卡、交易、支付或追溯平台。cURL地址 `https://sandbox.example.invalid/open-api/v1` 是不可解析的占位地址。文档与演示对象均为合成样本，不读取生产数据。

公开摘要须由权利人主动发布；记录、工单、样品与资料包必须有有效对象授权。农户成本、家庭信息与原始GPS轨迹不向合作采购应用开放。服务凭据仍待委托方验收，报告仍待核验，追溯预检没有官方回执。农户生产端不收费。

## 正式实现前必须补齐

服务端应用审核与令牌生命周期、主体/对象授权与撤回、字段最小化、用途限制、持久幂等与设备事件去重、设备签名及卡片绑定校验、实际限流与审计、可信媒体归属、配额/商业权益、外部平台协议映射、回调地址安全校验/签名/重试。正式密钥不能由浏览器保存或校验。

OpenAPI导出遵循[OpenAPI 3.0.3](https://spec.openapis.org/oas/v3.0.3.html)结构，但属于未部署的设计草案，返回体字段的完整业务Schema仍待与正式后端共同定版。
