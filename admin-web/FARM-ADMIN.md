# 乡桥农事管理后台：本次扩展

在原有 React / TypeScript / Vite 后台基础上实现，保留社员、地块核验、服务工单、供需、系统设置与审计页面。没有新安装依赖，没有修改真实支付、硬件或政府平台。

## 本地运行

```sh
cd admin-web
npm run dev -- --port 4174
```

地址：http://127.0.0.1:4174/ 。演示登录沿用原项目的手机号与验证码 `000000`。开发服务器只监听本机。

## 新增页面

| 路径 | 功能 |
| --- | --- |
| `/cards` | 卡片激活绑定、A/B/C配置版本、挂失恢复、BLE模拟同步 |

| `/production` | 产季和多年种植档案、照片＋视频变更申请、模拟审核与旧版本保留、成熟及产量预测设置 |
| `/soil` | 土壤报告登记、pH/有机质与机构建议、模拟核验归档 |

| `/verification` | 乡桥农事记录认证体系的内部核验规则和缺项进度 |
| `/trace` | 内部资料预检、JSON预览导出、模拟失败和同任务重试 |
| `/maturity` | 成熟窗口、预计产量、授权意向供应规模及分布示意 |
| `/resources` | 冷库、农机手、农服队、农资门店与加工资源示意及设备接入要求 |
| `/inventory` | 共享库存、B级货需求、kg/斤转换、锁定/释放/出库 |

新增页面按5个模块懒加载；首页增加乡桥记录闭环入口，导航支持分组、滚动、折叠及手机抽屉。原地块详情可跳转产季档案，只有已建立示例档案的地块显示对应信息。

## 可验证的流程

1. 卡片管理 → 发布A/B/C版本 → 平台v2/设备v1 → 模拟同步 → 两者v2。历史事件保留原配置版本。
2. 农事记录 → 原始事件核验。离线事件必须先同步；纠偏另存地块和说明，不覆盖原始事件。
3. 地块档案 → 申请种植变更 → 照片与视频两类都必需 → 待审核 → 模拟通过留旧版本。变更后预测标记待重新核实，不将原作物产量和成熟期直接发布给新作物；需另行保存成熟与产量预测。
4. 库存 → 锁定2000斤（1000kg） → 可用量下降 → 取消释放或出库转已售；不允许超售或重复出库。
5. 完成地块待核验记录与土壤归档 → 报送预检 → 本地DEMO任务 → 模拟超时 → 同任务重试。

## 明确边界

- 当前为前端演示，`src/farm/model.ts` 提供纯状态转换，`FarmProvider` 保存版本化本地事件日志（最多1000次操作）。不会修改原后台的mock存储。
- 不要录入真实个人信息。没有多用户同步、正式鉴权、审核角色隔离、不可篡改审计或服务端库存事务。本地锁库存不提供并发保障。
- 照片/视频仅检查文件类型与大小、保存名称/类型/大小；**没有上传内容或判断真实性**。不将元数据模拟审核当作实际认证。
- GNSS、BLE、NFC、电力、视频和传感器均未接入；地图为示意布局。硬件尺寸与续航为研发目标而非已验证规格。
- 乡桥内部核验不等于绿色食品标识、农残检测合格、食品安全认证或第三方认证，正式发证未启用。
- 一品一码未接入。预检规则和JSON不是其官方标准；模拟完成没有政府平台回执，未生成正式追溯码。
- 初始样本与库存保鲜期筛选以2026-08-29为基准，操作留痕用本机当前时间；入库保鲜截止日不能早于本机入库日。500亩、20/1000/10000张和第二年1000用户为规划目标。
- 成本35%为加价率，不是毛利率或保底价。默认工日按家庭劳动机会成本计算，雇工现金费用计入服务项，避免重复。其他项可能含折旧等非现金分摊，未把该小计称为现金成本。
- 意向可售预测与仓库实存分开；自营合同金额不是到账，购销账面差价不是净利润。没有付款、合同签署或真实发货。
- 商家收费方案只是管理端示例，生产记录端和消费者展示认购入口不收平台费用。未实现支付或按条实际扣费。

## 下一阶段接口

硬件：设备认证、唯一事件序号/幂等去重、按键版本与设备回执、BLE断点上传、NFC授权读写。

服务端：农户/子女/合作社/商家角色、定位与展示授权、审核分权、对象存储附件、机构报告版本、地块边界、服务单与投入品批次、并发锁库存及结算。

外部平台：一品一码正式授权与字段适配、外部回执/重试幂等；地图服务；环境设备遥测；脱敏消费者公开数据。不得直接公开本地演示状态或农户私有成本。

## 检查

```sh
npm run build
npm run lint
npm test
```

新增测试覆盖卡片版本与授权、不可覆盖的原始日志、媒体双材料校验、库存数量守恒、重复履约拦截、成本公式、预检阻断/重试、页面表单与缓存异常。

本次验证结果：构建通过、ESLint零警告、7个测试文件共45项测试通过；内置浏览器检查13个新增路由和核心流程，控制台无警告或错误。1280px桌面与390px手机布局无整页横向溢出，手机菜单能展开并在导航后收起。Safari尚未实机验证。
